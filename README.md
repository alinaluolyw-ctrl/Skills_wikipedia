# 📚 Skills Wikipedia

A modern web application for documenting your professional skills and generating professional proposals. Build your personal skills library and create polished proposals in seconds.

## Features

### 📖 Skills Library
- **Add & Organize Skills**: Store your professional skills with detailed descriptions
- **Skill Levels**: Rate your expertise (Beginner, Intermediate, Advanced, Expert)
- **Categorization**: Organize skills by category (Frontend, Backend, Language, etc.)
- **Easy Management**: Add, view, and delete skills with an intuitive interface
