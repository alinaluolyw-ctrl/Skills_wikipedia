# Skills Wikipedia

This repository is a curated collection of "skills" — notes and guides created and collected by the maintainer. It is not a full web product; instead it serves as a personal skills library where practical methods, templates, and short guides are gathered and organized.

## What you will find here
- Focus areas: personal growth, team management, organizational improvement, team training, marketing, work efficiency, and related dimensions.
- Individual skill files (Markdown) that summarize techniques, processes, templates, examples, and references.
- Zip archives containing supporting resources or packaged skill sets.

## How the repository is organized
- Skill files use plain Markdown and are named to make them easy to find (for example: `*-SKILL.md`).
- Large collections and resource bundles are stored as .zip files in the repo root.
- Each skill file is intended to be self-contained: a short description, steps or tactics, and any links/resources.

## How to read and use the content
- Browse the repository to find topics of interest (the filenames and top-level directories indicate the subject).
- Open a skill file to read the summary, practical steps, and links to further reading or downloadable assets.
- These notes are written for quick reference and practical application — treat them as concise guides rather than exhaustive tutorials.

## Contributing or adding new skills
- If you want to add or update a skill, create a Markdown file following the repository style:
  - A clear title
  - A short summary (1–3 lines)
  - Practical steps / templates / examples
  - Optional: references, assets, or exported files (zip)
- Consider using a filename convention that includes the topic and `SKILL`, e.g. `team-onboarding-SKILL.md`, to keep files discoverable.
- Open a pull request with a short description of the addition or change.
